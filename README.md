# House Price Prediction Using Simple and Multiple Linear Regression

## 📌 Project Overview

This project implements **Simple Linear Regression and Multiple Linear Regression** to predict median house values using the California Housing dataset. It was developed as part of **AI & ML Internship — Task 3**.

The project demonstrates data preprocessing, exploratory data analysis, model training, evaluation, visualization, and regression coefficient interpretation using Python.

## 🎯 Objectives

- Implement Simple Linear Regression using a single independent variable.
- Implement Multiple Linear Regression using multiple independent variables.
- Preprocess and analyze the dataset.
- Split data into training and testing sets.
- Evaluate model performance using MAE, MSE, RMSE, and R² score.
- Visualize regression relationships and model predictions.
- Interpret regression coefficients and analyze residuals.

## 📊 Dataset

**Dataset Name:** California Housing Dataset

**Source:** Scikit-learn

The dataset contains housing-related information, including:

- `MedInc` — Median income
- `HouseAge` — Median house age
- `AveRooms` — Average number of rooms
- `AveBedrms` — Average number of bedrooms
- `Population` — Population
- `AveOccup` — Average household occupancy
- `Latitude` — Geographic latitude
- `Longitude` — Geographic longitude
- `MedHouseVal` — Median house value (target variable)

## 🤖 Models Implemented

### 1. Simple Linear Regression

Uses median income (`MedInc`) as the independent variable to predict median house value (`MedHouseVal`).

**Equation:**

`Y = β₀ + β₁X`

### 2. Multiple Linear Regression

Uses all available housing features to predict median house value.

**Equation:**

`Y = β₀ + β₁X₁ + β₂X₂ + ... + βₙXₙ`

## 📈 Evaluation Metrics

The models are evaluated using the following metrics:

- **Mean Absolute Error (MAE):** Measures the average absolute prediction error.
- **Mean Squared Error (MSE):** Measures the average squared prediction error.
- **Root Mean Squared Error (RMSE):** Expresses prediction error on the target's original scale.
- **R² Score:** Measures how much of the target's variation is explained by the model on the evaluated dataset.

The evaluation results are generated by executing the notebook.
